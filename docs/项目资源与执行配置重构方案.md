# 项目资源与执行配置重构方案

本篇记录 2026-11-20 修订稿的工作台和配置归属。2026-11-21 修订后，项目工作台、变量集合、节点交付配置及产物实物管理按 [项目交付重构实施计划](项目交付重构实施计划.md)执行。

## 实现基线

修订稿以 `d80f482` 为审查基线。`a0c9031` 提供类型化图、具名制品与按 SHA 的审核，`588efec` 提供引用反查、版本停用和事务内移除保护。后续 `5708a11` 已提交统一运行预览、四入口工作台和迁移 `024_environment_execution_settings`。各领域的实现、遗留兼容和验证范围见 [实施与验收计划](需求梳理与实施计划.md#项目工作台整改开发步骤)。

## 项目入口与资源边界

| 一级入口 | 主操作与上下文 |
| --- | --- |
| 项目资源（默认） | 顶部摘要提供服务、环境和最近运行，下面按仓库、服务、环境、服务器与分组和访问地址查看。图中选中的资源可跳到详情，详情可返回引用它的流、节点或记录。 |
| 执行图 | 一张项目画布承载多个开始入口。服务的“运行”进入对应发布版开始节点，带入服务和环境；共享节点面板随所选流显示输入来源。 |
| 交付记录 | 按服务、环境、提交查看构建产物、部署与回滚、待审批发布。历史展示当次目标、来源运行、图版本、生产节点和实际消费的制品。 |
| 项目配置 | 同页编辑基本信息、执行默认值、项目公共变量和 AI 策略。展示 AI 生效模式、范围和继承来源，支持管理员覆盖或恢复继承。系统设置负责 Provider、密钥、用途路由和系统默认策略；服务环境维护故障处理开关。 |

服务器、分组、凭据和镜像仓库由平台登记，项目保存或展示授权范围内的引用。项目服务器清单按主机 ID 去重，保留直接引用、分组及成员、旧目标、图中固定服务器或目标绑定的来源。区分草稿、可运行的发布版本和待执行计划；仅在某次运行动态选中的服务器进入运行历史。分组成员变化后，资源页展示当前成员，历史显示原快照。AI 资源选择器显示名称和原有引用，资源被项目使用本身不授予 AI 操作权。

页面 URL 保留资源类型、对象、服务环境、配置分区、筛选及返回的项目视图。兼容 `execution-graph?start=…`、`?run=…`、`?pane=history` 及已有产物、部署、审批地址。刷新、前进后退、复制链接及图与资源往返应恢复同一对象。切换带未保存改动的草稿时允许先保存或放弃。通过直接地址访问也要校验角色及项目归属。服务详情提供匹配的发布入口、目标来源与最近发布，依赖详情可查依赖及被依赖项。

## 字段归属与生效顺序

| 配置 | 编辑入口与取值规则 | 预览或失败行为 |
| --- | --- | --- |
| 构建位置、并发、工作区根、日志保留 | 系统提供默认，项目可覆盖。构建节点可显式指定执行位置；允许调整并发的运行使用已声明的输入。工作目录相对于选定工作区。 | 显示最终值、作用域和来源版本。管理端仅构建只校验隔离执行环境；目标端构建必须解析构建服务器。 |
| 仓库与检出版本 | 仓库登记克隆地址和凭据，连接后探测远端分支及默认分支。服务仓库关联用于展示与推荐。Git 节点接收同项目且获授权的仓库和分支、Tag 或提交，允许多仓库独立检出。 | 显示每个 Git 节点的实际仓库、ref、固定 SHA 和工作区。URL 可匹配已登记仓库，缺失时由有权限者登记后回填。 |
| 环境与环境文件 | 运行选择、触发映射或入口默认值确定环境。节点显式文件优先，其次使用环境配置路径，最后可探测约定文件；文件属于对应 Git 节点的固定提交。 | 预览列出仓库、SHA、相对路径、来源和是否必需。显式文件缺失或越出工作区时阻止消费；可选探测未命中时标记跳过。 |
| 普通变量与敏感变量 | 同名键由低到高依次取仓库环境文件、项目公共变量、项目环境、服务环境、节点显式绑定。先选择有效来源，再按权限注入。平台保留键由系统提供。 | 显示键、覆盖层和敏感引用状态。预览、图快照、日志不保存或显示敏感明文。仅录入服务环境变量时，可在尚未配置发布目标的情况下保存。 |
| 构建目标 | 管理端使用隔离运行器。目标端从构建节点的目标绑定或显式引用解析服务器及分组。 | 管理端仅构建不展开已经配置的发布目标。目标端缺少构建服务器时定位到对应构建节点。显式 SSH 检查按自己的目标解析。 |
| 发布目标及发布配置 | 依次采用允许的本次选择、服务环境覆盖、项目环境默认目标。清除覆盖即恢复继承。服务环境拥有发布方式、目录、Compose 来源、启停、健康检查、审核、审批及回滚。 | 展开后按服务器 ID 去重并保留全部来源，显示成员、并发与失败策略。区分空分组、停用、不可达、缺凭据及目标范围冲突。 |
| 构建与制品 | 构建模块维护相对目录、命令、具名产物和必需性。文件、目录记录归档校验值，镜像记录不可变 Digest 或已校验的离线归档。部署模块接收登记过的产物引用。 | 区分已固定的历史 ID 与本次预期产出的节点／字段。本次归档完成后补记实际 ID；构建失败时停在构建阶段。 |
| 源码审核与发布审批 | 源码审核按产物实际依赖的仓库及完整 SHA，服务环境决定是否必需。发布审批针对本次固定制品、目标与环境。 | 分别展示审核和审批结果。产物来源无法核实、审核被撤销或目标权限变化时，在对应放行点重新检查。 |

例如，在测试和生产都检出同一版本时，预览应分别显示“环境文件 `.env.test`，来自测试环境”和“环境文件 `.env.prod`，来自生产环境”。同页还应显示“镜像来自本流构建节点的 `image` 输出”或“镜像来自开始参数指定的历史制品”。若服务关联的主仓库为 A、实际 Git 输入为 B，预览和产物溯源均记录 B。当前人工审核记录按项目、服务、环境和 SHA 标识，检查节点成功只生成该步骤结果。多仓构建需先确定受审源码集合并将仓库 ID 与实际 SHA 关联到制品，才能判断一次审核覆盖哪些输入。

### 环境文件与独立保存

- 环境决定选择文件，Git 输入决定读取的提交。显式文件必须是所绑定源码工作区内的相对路径，缺失、不可读、类型或大小不合规、越界时阻止消费。约定探测使用节点工作目录中的 `.env.<环境标识>`，未命中时在预览中标明探测路径并跳过。使用通用 `.env` 时需显式配置。
- 预览标明文件的仓库、固定 SHA、路径、来源及必需性。能在 Git 元数据中确认的文件提前校验，依赖已生成工作区的检查在消费前完成。变量按键选出生效值，再按权限解析值。空字符串是有效覆盖，删除覆盖恢复上一层，平台保留键禁止写入。
- 表格和 dotenv 文本共用草稿，`# @secret KEY` 作用于其后对应的赋值。重复键、孤立标记、非法语法、保留键和错误掩码须定位并阻止整批保存。两视图切换保留有效改动和变量说明。敏感项加密存储，复制和导出默认掩码，读取明文受角色限制并审计。
- 服务与环境组合按 `serviceId + environmentId` 唯一。服务环境变量、发布策略和目标可以独立保存。有效发布参数缺项时呈现待配置，并在消费节点定位缺项。按作用域提交变量时要求原子写入和并发变更检查。

### 制品消费及源码证明

- 组合流按绑定消费本次构建的结果。独立部署由入口选择历史制品，或显式启用「最新兼容」规则。预览在成功批次中按名称、类型、存储和目标兼容条件确定 ID 及摘要。多目标发布使用同一批次并逐目标匹配来源服务器。
- 以产物实际依赖的仓库和 SHA 判断审核。触发仓库和事件 SHA 单独记录，保留每次检出的 ref、工作区及来源关系。首轮按单仓库验证，之后扩展逐产物依赖集合。无法核实来源的历史审核保留供查阅，确认仓库后重新建立有效审核。
- Compose 模板由服务环境选择维护的文件或制品归档中的版本化文件。发布及回滚计划记录模板路径、摘要和实际镜像引用。跨环境制品提升安排独立规则和审计。

## 共享节点与运行计划

1. **草稿与发布。** 草稿可保存缺项。开始声明参数，结束声明结果，流通过端点和选定连线定义。字段使用稳定 ID、类型、必填性及单值或多值约束。每条流独立绑定共享节点的输入和结束输出，可取开始参数、固定值、平台上下文或本路径可用的上游结果。发布时固定图和模块版本，检查项目归属、端点、环、普通分叉歧义和每条成功路径的必需数据；错误定位到流、节点和字段。
2. **预览与确认。** 预览、确认和派发共用解析规则。显示路径、参数、源码、命令、构建与发布目标、环境文件、变量元数据、制品、审核和审批。已有制品在预览固定 ID，未来产物固定生产节点、名称、类型和兼容条件。确认提交 `expectedConfigurationHash` 和幂等键，有效配置、组成员或制品变化时标出差异并要求重新预览。相同请求和键取回原运行，重复使用同一键提交不同请求时返回冲突。
3. **执行与交接。** 每次检出分别输出仓库、实际 SHA、ref、提交说明和工作区引用；触发事件另存事件 ID、时间、ref、提交，允许一个事件启动多仓库运行。Shell 和构建只能消费本次授权工作区的相对路径，允许显式传入 `outputDir`。同一构建可登记 `jar`、`static`、`image`；Shell 生成的文件须经登记后交给部署。跨主机及跨运行消费时检查可达性、摘要、服务环境和目标兼容性。
4. **派发与恢复。** 手动、Webhook、定时、API 和上游入口使用同一参数及策略校验，启用规则前须为每个必填参数配置映射、默认值或合法选择规则。条件运行只消费已确认计划允许的路径及产物，派发前复核权限、目标状态、SSH 身份、凭据、发布保护及产物完整性。恢复沿用原版本和快照，扩大目标或改变有效计划须重新确认。取消传播到尚未执行的任务，外部结果不确定时进入 `NEEDS_ATTENTION` 并保留核查证据及必要的锁。自动交付按入口验收。

画布保留拖入、复制节点和删除连线的操作。固定审核路径由该流选定的控制连线决定，运行时按参数选择是否审核才使用判断节点。并行汇合等待本次实际参与的分支。结束节点若声明“本次构建产物”，每条可成功结束的路径都须返回本次登记的具名制品；若声明“服务发布结果”，须绑定本服务、本环境实际成功的部署结果，来源可为部署模块或已发布子流。复用节点时，改变一条流的绑定应保留其他流的输入与输出。

## 引用保护与迁移

- **反查与并发。** 资源详情列出引用它的配置、流、版本及待执行计划。发布和资源移除在事务内复核同一资源状态。归档后退出新选择；仍有可运行版本或待执行计划引用时，提示受影响对象，先替换或停用相关配置。仅有已完成历史时保留快照与稳定 ID。派发前复核凭据、服务器和权限。
- **盘点及备份。** 保存数据库、解密材料、日志和制品。盘点缺图项目、旧 `START.delivery`、旧 Pipeline、重复构建字段、旧目标、审核记录、固定版本触发器和在途任务。
- **存量映射。** 按项目唯一键为缺图项目幂等补建草稿，保留已有草稿和发布版。构建字段迁入构建模块，部署字段迁到服务环境或部署输入，保留端点、路径与各流绑定。旧目标记录其原有展开规则。旧 `BUILD_ONLY`、命令、工作目录、产物或目标冲突列入人工确认清单。
- **切换与恢复。** 用同一输入对照新旧路径、运行模式、实际仓库和 SHA、命令、工作区、环境文件、变量、目标、产物与审批。确认后切换发布入口和触发规则，保留旧版本、历史记录、事件处理状态以及已确认在途快照。演练停用新入口、恢复可用旧版或重新发布草稿，按既有权限及引用规则校验并避免重复触发。SQLite 与 PostgreSQL 均验证重复迁移、切换及恢复。

### 数据与接口边界

项目图按项目唯一，草稿按修订号并发更新，发布版按图与版本唯一并记录停用时间。运行持久化版本、入口、输入、事件、父运行、配置摘要和来源快照，节点按运行与节点 ID 唯一并关联任务、子运行、结果与日志。变量按作用域和键唯一，普通值和敏感引用分别保存。制品与发布沿用稳定 ID，补齐来源仓库与 SHA、节点、批次、摘要及当次逐目标结果。预览以节点分组返回生效值、来源与校验信息，确认使用相同契约，过期、冲突、缺值与越权分别反馈。迁移期间继续支持旧记录查询。已实现的 HTTP 字段以 [API 文档](API.md) 为准。

## 首轮验收

使用同一个 Web 服务、测试和生产两个环境、一张发布图及一个固定 Git SHA。四条流共享构建或部署节点，以运行计划、节点输出、制品记录和实际发布结果判定通过。

| 执行入口 | 必须观察到的结果 |
| --- | --- |
| 仅构建 | 管理端无发布目标仍可构建；再用带有生产默认目标的环境验证打包期间无发布目标连接。归档 `jar` 和 `image` 两个具名产物。改为目标端构建且缺少构建服务器时，预览指出缺项。 |
| 审核并构建 | 使用同一构建节点，经选定的审核路径运行；普通直连不能绕过该流固定的审核步骤。生产发布需要代码审核时，绑定其他 SHA 的结果或已撤销的结果均不能放行。 |
| 构建并部署 | 部署节点只取本次构建的 `image`。测试加载 `.env.test`，生产加载 `.env.prod`，展示各自实际目标、目录和审批；构建失败保留原服务。 |
| 仅部署 | 同一部署节点改由开始参数提供兼容的历史镜像。图发布时允许该值待选，运行时必须固定 ID 和 Digest。选错服务、环境、类型或来源目标时拒绝；无需重建。 |

交叉验证三类失败：必填产物只在一条条件分支产生时，发布诊断指出缺值路径；预览后组成员变化或资源停用时，确认应要求复核；两个项目共享主机时，资源反查和 AI 权限均保持项目边界。保留本次与历史产物的生产节点、触发事件与各 SHA、目标快照、审核决定及发布结果，用于复核与回滚。实施阶段见[总体实施计划](需求梳理与实施计划.md#项目工作台整改开发步骤)。
