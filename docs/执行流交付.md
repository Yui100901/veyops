# 执行流构建与部署

项目工作台包含「项目资源」「执行图」「产物」「项目配置」。服务负责访问地址和仓库关联，变量集合提供可复用的运行变量。构建、发布、审核、审批、健康检查和回滚的顺序由已发布执行图声明。

## 配置与编排

1. 在「项目资源」登记仓库、服务及环境变量集合。服务器与分组在平台「服务器」登记并核对 SSH 指纹。进入服务详情可访问已配置的地址及相关执行流。
2. 新项目的执行图已包含「最小构建并部署」草稿。在「执行图 → 编辑草稿」可使用工具栏的「插入流程模板」，一次加入一条独立执行流。开始节点可以固定、运行时选择或省略变量集合。构建和部署各自绑定服务器或分组。
3. 在构建节点固定仓库或绑定前序检出结果。设置工作目录、安装与构建命令、构建位置和具名产物。部署节点绑定服务、目标及本次或历史产物，并设置 `FILE` 或 `COMPOSE`、发布路径和需要的启停命令。
4. 保存并发布图。从已发布开始节点预览，核对实际仓库与 SHA、变量集合修订、构建及发布目标、产物和审核节点，再确认运行。

| 内置模板 | 默认接线 |
| --- | --- |
| 最小构建并部署 | 开始 → 代码拉取 → 构建 → 部署 → 结束。结束返回本次主产物和发布结果。 |
| 较完整的构建 | 开始 → 代码拉取 → 检查与测试 → 构建 → 结束。检查通过后构建并保存产物，同时返回检查报告。 |
| 较完整的部署 | 开始 → 人工审批 → 部署 → 发布健康检查 → 结束。可选择已登记的历史产物，结束返回经检查的发布结果与健康状态。 |

模板插入时可选文件、目录或 Docker 镜像，默认目录。草稿可以先保存，发布检查会定位待补配置。源码审核可关联实际构建并绑定 `review` 凭证。选择旧产物后会生成一次新的发布。图内回滚使用「按产物回滚」节点，绑定本次发布结果 `afterRelease` 并核对逐目标基线。

同一执行流的普通出线并行，普通节点或结束的多条入线等待本次参与的上游。条件分支按匹配值选择稳定的出口 ID，未匹配时走默认出口。主工作区可交给自定义 Shell 或检查节点，在「输出」声明正式产物。关闭保留的产物由当前根运行及其子流消费。

## 构建与变量

Git 拉取接受分支、标签或完整提交。预览固定实际 SHA。管理端构建在配置的隔离 Docker 运行器执行，可省略发布目标。目标端在确认的服务器准备独立工作区，默认根目录为 `~/.veyops/workspace`，项目可覆盖。

变量按仓库文件、项目公共变量、开始节点变量集合、节点显式绑定逐层覆盖。将变量文件加载节点绑定到固定源码，并填写明确的相对路径，或将 `ENV` 映射到 `.env.test`、`.env.prod`。必需文件缺失会阻止消费者执行；可选文件缺失时显示跳过。

变量集合支持表格和 dotenv 文本编辑。用 `# @secret KEY` 标记敏感变量，保留掩码时沿用原值。敏感值的明文查看受权限限制并写入审计。构建节点可将检出的 `commitSha` 绑定到 `GIT_SHA`，并在预览及运行详情核对来源。`VEYOPS_*` 系统键由平台注入。

具名产物可为文件、目录或镜像。目标端产物登记实际构建服务器。部署核对发行位置、摘要或镜像身份，优先使用匹配的同机实例。明确配置分发时，文件归档或固定 Registry Digest 可用于匹配目标。

## 发布保护、审批与回滚

- 源码审核在相关运行节点处理。关联构建的审核固定主仓、依赖仓和独立变量文件的实际仓库及 SHA。发布审批固定本次服务、服务器成员、实物实例和指纹。计划或权限变化时需重新核对。
- 文件发布校验归档并准备 `deployPath/releases/<task-id>`，再更新 `current`。Docker Compose 的模板可以来自产物归档，或固定仓库、提交与路径。Compose 文件通过 `${VEYOPS_IMAGE}` 使用已验证的镜像。预览及应用时核对模板内容摘要。
- 健康探针在已激活的版本目录执行。退出码 `0` 表示健康，`10` 表示明确不健康。「健康才通过」模式在不健康时终止该链的后续步骤并保留检查证据。「报告健康状态」模式可用条件分支进入已配置的回滚。缺工具、超时、SSH 中断或发布结果不确定时进入待核查。
- 从运行详情对异常服务器发起只读核查，查看当前链接、发布锁和可确认的版本。符合条件时，从原版本重新预览。回滚恢复应用发布，数据库及持久数据使用独立的[备份与恢复](BACKUP.md)流程。
- 「产物」可查询、验证、固定保留、提交清理或跳到生产节点。同一主机上的独立发布位置分别保护活动产物。当前版本、最近健康版本及执行中保留的产物由清理规则保护。

服务环境默认发布目标、单独部署目标及旧交付操作属于历史记录。新发布、审批和回滚在执行图及运行详情操作。
